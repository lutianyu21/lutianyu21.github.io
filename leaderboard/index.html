Details

Score = mean TMus × 100. The table reports means; medians are included in the metric data. TMus, TMaa, GDT-TS and LDDT use the 0–1 scale; RMSD uses Å.

Sources. Published results take precedence over local re-evaluations of the same model and size. Other rows use existing local evaluations. These protocols differ. Paper ESM3, ESMDiff and EigenFold use historical TMscore -seq values in the TMus column. Missing paper metrics are shown as —.

Sampling. Ctrl marks oracle sampling configurations using native structures; these rows participate in sorting but do not receive numeric ranks. @k indicates the sampling budget. DPLM2 selects one candidate by TMus and reports all metrics from that structure; BioMatrix selects each metric independently. Greedy results are omitted; @1 uses the first sampled candidate.
